# SAIT Capstone Project — Secure Home Hub

**April–December 2023 · Southern Alberta Institute of Technology, Calgary, AB**

- Collaborated in a six-person team to develop a Raspberry Pi 4 smart-home hub combining IoT connectivity, device enumeration, network monitoring, and firewall controls on Ubuntu 22.04 LTS.
- Took responsibility for Raspberry Pi security configuration, developing and inspecting iptables rules and using UFW during firewall troubleshooting.
- Documented firewall policies, device-access rules, logging approaches, and security integration considerations for the team.
- Investigated local port-display issues and documented revised output to support device administration and troubleshooting.

Team project context: touchscreen and USB integration, an Ubuntu Wi-Fi hotspot, SSH/RDP/GitHub remote-development workflows, and Snort/Scapy network functionality. Attribute these as personal accomplishments only where individual responsibility is confirmed.
